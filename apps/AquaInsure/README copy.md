# Aqua AInsure

Smart Insurance & Record Keeping for Aqua Farmers.

## Project info

This application is designed to help aqua farmers manage their farm records, track daily entries, and facilitate insurance claims with transparent data.

## Getting Started

### Prerequisites

- Node.js & npm installed

### Installation

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd aqua-ainsure

# Step 3: Install dependencies
npm i

# Step 4: Start the development server
npm run dev
```
